Create verified, portable WordPress backups and recover locally or from Cloudflare R2 and Amazon S3.

== Description ==

ZoeCloud creates portable version 2 backup archives for real WordPress sites. It protects integrity before recovery, runs long operations through durable background jobs, and keeps local archives behind authenticated downloads.

Highlights:

* Back up the WordPress database and files with per-component SHA-256 checksums.
* Use cryptographically random local storage names in a protected private directory.
* Run backup, upload, download, and restore work independently from the browser.
* Resume abandoned jobs through atomic leases, bounded retries, and WP-Cron reconciliation.
* Verify ZIP paths, symbolic links, component sizes, compression ratios, manifests, SQL, and checksums before registration or restore.
* Create and verify a mandatory full safety backup before every restore.
* Stage database tables and files before the final exchange, with rollback journals and recovery instructions.
* Restore across different WordPress table prefixes.
* Upload to and recover from Cloudflare R2 or Amazon S3 without bundled cloud SDKs.
* Use WP-CLI for unattended operation and emergency recovery.
* Keep backups when the plugin is deactivated or uninstalled unless explicit deletion consent is enabled.

ZoeCloud does not use telemetry and does not contact external services automatically. A configured R2 or S3 service is contacted only when an administrator explicitly tests it, requests a cloud operation, or enables cloud upload for scheduled backups.

== Installation ==

1. Upload the `zoe-cloud` folder to `/wp-content/plugins/` or install the ZIP from WordPress.
2. Activate ZoeCloud.
3. Open **ZoeCloud** and complete the environment diagnostic.
4. Optionally configure Cloudflare R2 or Amazon S3.
5. Create the first backup and verify it before relying on the schedule.

For reliable background processing, configure the system scheduler to run WordPress cron regularly. You may also run:

`
wp zoecloud jobs run
`

== Backup format ==

Version 1.0 restores ZoeCloud backup format v2 only. Each ZIP contains:

`
files/
database.sql
checksums.jsonl
manifest.json
`

The manifest records the origin URLs and hostname, source table prefix, scope, WordPress/PHP requirements, table and file counts, sizes, and component checksums. Restore accepts only the SQL grammar generated by ZoeCloud and only tables declared by the manifest.

There is no automatic migration from ZoeCloud 0.2 settings, jobs, records, or backup archives.

== WP-CLI ==

`
wp zoecloud backup create [--full] [--cloud]
wp zoecloud backup list
wp zoecloud backup verify <backup-id>
wp zoecloud restore <backup-id> --hostname=<current-hostname> [--search=<url>] [--replace=<url>]
wp zoecloud jobs run
wp zoecloud doctor
`

== Recovery procedure ==

1. Run `wp zoecloud doctor`.
2. List local recovery points with `wp zoecloud backup list`.
3. Verify the selected archive with `wp zoecloud backup verify <backup-id>`.
4. Run `wp zoecloud restore <backup-id> --hostname=<current-hostname>`.
5. Confirm the destructive operation when prompted.

Every restore first creates a verified full local safety backup. If the automatic rollback cannot finish, the failed job message includes the exact safety backup ID and a WP-CLI recovery command. Do not delete that safety archive until the site has been checked.

== External services ==

Cloud storage is optional.

= Cloudflare R2 =

When an administrator configures R2 and explicitly tests, uploads, lists, downloads, deletes, or enables scheduled cloud upload, ZoeCloud sends signed S3-compatible requests to the account endpoint. Requests may include the backup ZIP, bucket and object key, SHA-256 metadata, and the configured access-key identifier. The secret access key is used locally to sign requests and is not transmitted as plaintext.

* Service: https://www.cloudflare.com/developer-platform/products/r2/
* Terms: https://www.cloudflare.com/terms/
* Privacy: https://www.cloudflare.com/privacypolicy/

= Amazon S3 =

Under the same explicit conditions, ZoeCloud sends signed requests to the configured Amazon S3 bucket. The transmitted data may contain the complete backed-up site, including personal data already stored by WordPress.

* Service: https://aws.amazon.com/s3/
* Service terms: https://aws.amazon.com/service-terms/
* Privacy: https://aws.amazon.com/privacy/

Use credentials restricted to the intended backup bucket and prefix.

== Privacy ==

ZoeCloud does not collect telemetry, place tracking cookies, load remote assets, or send data to the plugin author.

Local backups can contain the full WordPress database and files and therefore may contain personal or confidential data from the site. They are stored in a randomized private directory and are downloadable only by authenticated administrators with `manage_options`.

If optional cloud storage is enabled, backup contents are sent to the administrator-selected R2 or S3 account. Site owners remain responsible for retention, access control, regional storage, and deletion policies for those copies.

Job events are sanitized, bounded, administrator-only, and never include cloud secrets. Cloud credentials are encrypted with AES-256-GCM using key material derived from WordPress salts.

== Frequently Asked Questions ==

= Are backups publicly downloadable? =

No. Stored filenames are opaque and downloads require an authenticated administrator endpoint. Web-server deny files are added as defence in depth, but security does not depend on those files.

= Does restore accept any SQL dump? =

No. Public restore supports only ZoeCloud v2 archives. SQL statements and table names outside the signed manifest scope are rejected.

= Can I clear the Activity history? =

Yes. The Activity tab has a **Clear activity** action that removes finished and failed job records and their event logs without touching backups or active jobs. ZoeCloud also keeps the newest 100 finished jobs automatically.

= Will uninstall delete my backups? =

Not by default. Enable the explicit destructive uninstall option first if you want ZoeCloud to remove its tables, settings, and local backup storage.

= Does ZoeCloud work when WP-Cron traffic is unreliable? =

Yes. Use a system cron to invoke `wp zoecloud jobs run`. ZoeCloud also recreates missing recurring WP-Cron events.

= Does ZoeCloud support WordPress Multisite? =

Version 1.0 targets single-site WordPress installations.
